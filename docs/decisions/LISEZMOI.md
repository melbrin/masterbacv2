# Décisions

Une décision par fichier, numérotée : `0002-format-des-sources-de-quiz.md`. On écrit une décision quand un choix engage la suite, s'écarte de la documentation ou tranche une question posée à Yane. Une décision ne se modifie pas : une nouvelle la remplace et le dit.

## Modèle

```
# <numéro>. <titre qui dit le choix>

Date : AAAA-MM-JJ
État : proposée | acceptée par Yane | remplacée par <numéro>

## La question
Ce qu'il fallait trancher, en deux ou trois phrases.

## Les options
Pour chacune : ce qu'elle apporte, ce qu'elle coûte.

## Le choix
L'option retenue, et pourquoi.

## Ce que ça change
Fichiers, règles, tests, documentation touchés. Ce qu'il faudrait pour revenir en arrière.
```
